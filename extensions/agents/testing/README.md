# Testing

This tree holds the project's end-to-end test cases. A case is one markdown file under
`test-cases/<area>/`, carrying its inputs, its criteria, and the steps a run follows; the file's path
is the case's identifier. `AGENTS.md` beside this file holds the runners and the commands that run
them. Run output that is not committed goes to `.artifacts/`.
