# docs/visions — operative rules

- `archive/` is history. Do not read it unless the user asks about a superseded vision by name.
- `sources/` holds the material visions were written from, verbatim. Never edit one.
- Mockups that arrived with a vision live in `docs/mockups/`, cited from its `Related` line.
- A vision's identifier is permanent. `VISION-003` means the same document after it is archived.
- Status transitions are `/envision`'s to make, never a hand edit.
